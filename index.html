What's New in ONS2

Upgrades that take the Odin Navigation Stack beyond ONS1.

Dramatically faster planning

Plans substantially faster even on low-compute platforms, with smoother execution and nimbler obstacle avoidance.

Upgraded VLM, bring your own model

Connect a more capable vision-language model to your own workstation for richer scene understanding.

Built for industrial inspection

Extensive optimizations tuned to real industrial inspection scenarios and long patrol routes.

End-to-end, fully open source

A complete inspection workflow — simulation to real robots, algorithms to the monitoring platform. See the Real2Sim tutorial.

Plugin architecture

The stack is built around a plugin-based design, making it straightforward to integrate custom planners.

More on the way

Further capabilities will land in upcoming releases.

Odin1 On-Robot

Working with Odin1

This project showcases multiple demo pipelines built on Odin1. Each demo can be used independently or combined as an integrated stack.

SLAM

Build 3D maps for fast, persistent relocalization, providing positioning anchors for navigation.

It may take some time to load the 3D model.

Navigation

Long-range navigation through complex skybridges connecting multiple buildings: one complete round trip of about 640 m, with ONS 2 maintaining precise localization and stable online navigation, free of localization drift or map misalignment.

Real-to-Isaac Sim Simulation Navigation

Replicate real-world environments in Isaac Sim using Q9000 or odin1 collected data, import robot models (e.g., URDF), and perform navigation and manipulation tasks in a simulated setting.

Navigation in 3DGS Reconstructed Scenes

Built from Q9000-scanned 3DGS maps, the ONS 2 dashboard also runs in photorealistic indoor scenes: move the viewpoint freely and dispatch virtual robots to navigate.

More Exciting Features in Development

ONS2 keeps growing. Beyond this release, we are actively developing experimental modules—including multi-floor navigation and human-aware motion planning. Stay tuned for updates!
